# DS-01 栈与队列应用

> 定位：难度最低、最能稳定拿分的顶点，是"送分边界"。

## 一、为什么它是凸包顶点

栈与队列位于凸包的**左下角**——考频中等、难度最低。它界定了 408 数据结构的"难度地板"：

## 二、核心知识清单

### 2.1 栈（LIFO）

| 考点 | 关键结论 |
|------|---------|
| 出入栈序列合法性 | n 个元素不同入栈顺序，合法出栈序列数 = **Catalan 数 C(2n,n)/(n+1)** |
| 合法性判定 | 模拟：任何前缀中"出栈次数 ≤ 入栈次数" |
| 括号匹配 | 遇左括号入栈，遇右括号弹栈比对，结束时栈空 |
| 表达式求值 | 中缀 → 后缀（运算符栈，按优先级弹栈），后缀求值（操作数栈） |
| 递归消除 | 函数调用栈帧 = 系统栈；二叉树遍历非递归 = 显式栈 |

**中缀转后缀规则**（选择题高频）：
1. 操作数直接输出；
2. 左括号入栈；
3. 右括号 → 弹栈输出直到左括号；
4. 运算符 → 弹出所有**优先级 ≥ 它**的栈顶运算符后入栈；
5. 扫描结束，弹空栈。

### 2.2 队列（FIFO）

| 考点 | 关键结论 |
|------|---------|
| 循环队列判空 | `front == rear` |
| 循环队列判满（牺牲一单元） | `(rear + 1) % MaxSize == front` |
| 队列长度 | `(rear - front + MaxSize) % MaxSize` |
| 双端队列 | 限制一端出入后的合法序列判定（真题考过） |
| 队列应用 | 层序遍历、BFS、缓冲区 |

---

## 三、典型考法与真题锚点

1. **出栈序列合法性**（几乎年年选择题）：给一个出栈序列问是否可能 → 模拟栈验证。
2. **循环队列计算**：给 front/rear 求元素个数，或入队出队后求指针位置。
3. **综合题（2009/2012/2015）**：用栈或队列作为算法的辅助结构，例如借助栈完成某种转换。

**答题模板**：判合法 → 模拟过程画栈状态表 → 数操作次数。

---

## 四、易错点

- ⚠️ Catalan 数只能回答"总数"，判断**某个具体序列**是否合法必须模拟。
- ⚠️ 循环队列"判满"有两种约定（牺牲单元法 vs 计数器法），看题目定义。
- ⚠️ 双端队列出队序列：分"只从一端出"和"两端都可出"两种题型，结论不同。
- ⚠️ 中缀转后缀时，**相同优先级**的运算符也要弹栈（左结合性）。

## 例题精练（附答案）

### 例题 1：出栈序列合法性判断

**题目**：元素 a, b, c, d, e 依次入栈（允许穿插出栈），下列出栈序列哪个不可能出现？
A. d, c, e, b, a 　B. d, e, c, b, a 　C. a, b, c, d, e 　D. c, d, a, b, e

**参考答案**：选 **D**。

逐项模拟：
- A：push a,b,c,d → 弹 d, c → push e → 弹 e → 弹 b, a ✅
- B：push a,b,c,d → 弹 d → push e → 弹 e → 弹 c, b, a ✅
- C：入一个弹一个 ✅
- D：先弹 c（此时栈内 a, b，栈顶 b），弹 d 后栈顶仍是 b，**下一个只能弹 b，不可能弹 a** ❌

**判据**：任何时刻，栈中元素从栈底到栈顶保持入栈的相对次序；序列中若要先出"压在下面"的元素，必不可能。

### 例题 2：循环队列计算

**题目**：循环队列 MaxSize = 6，初始 front = rear = 0。依次执行：入队 ×5，出队 ×2，入队 ×1。求此时 front、rear 和队列长度。

**参考答案**：
- 入队 5 次：rear = 5；出队 2 次：front = 2；再入队 1 次：rear = (5+1) % 6 = 0。
- **front = 2，rear = 0**。
- 长度 = (rear − front + MaxSize) % MaxSize = (0 − 2 + 6) % 6 = **4**。

验算：队列中剩 5 − 2 + 1 = 4 个元素 ✅。

### 例题 3：中缀表达式转后缀

**题目**：将中缀表达式 `a + b * c − (d + e)` 转换为后缀表达式。

**参考答案**：`a b c * + d e + −`

过程（栈内自下而上）：

| 读入 | 栈 | 输出 |
|------|-----|------|
| a | | a |
| + | + | a |
| b | + | a b |
| * | + * | a b |
| c | + * | a b c |
| − | −（弹 * 和 +，因为 ≥ −） | a b c * + |
| ( | − ( | a b c * + |
| d | − ( | ... d |
| + | − ( + | ... d |
| e | − ( + | ... d e |
| ) | −（弹 + 和 (） | ... d e + |
| 结束 | 空（弹 −） | a b c * + d e + − |
