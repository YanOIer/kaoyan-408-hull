## 二、核心知识清单

### 2.1 存储结构（选择结构 = 选对复杂度）

| 结构 | 空间 | 适用 | 判边 (i,j) | 遍历出边 |
|------|------|------|-----------|---------|
| 邻接矩阵 | O(n²) | 稠密图 | O(1) | O(n) |
| 邻接表 | O(n+e) | 稀疏图 | O(度) | O(度) |

十字链表（有向图）、邻接多重表（无向图）——选择题考定义。

### 2.2 遍历（必背代码）

```c
// DFS —— 递归即栈
void DFS(Graph G, int v) {
    visited[v] = true; visit(v);
    for (w = FirstAdj(G, v); w >= 0; w = NextAdj(G, v, w))
        if (!visited[w]) DFS(G, w);
}

// BFS —— 队列
void BFS(Graph G, int v) {
    InitQueue(Q); visited[v] = true; EnQueue(Q, v);
    while (!IsEmpty(Q)) {
        DeQueue(Q, v); visit(v);
        for (w = FirstAdj(G, v); w >= 0; w = NextAdj(G, v, w))
            if (!visited[w]) { visited[w] = true; EnQueue(Q, w); }
    }
}
```

复杂度：邻接表 O(n+e)，邻接矩阵 O(n²)。

### 2.3 四大应用算法（手工模拟必考）

| 算法 | 问题 | 核心操作 | 复杂度(邻接矩阵) |
|------|------|---------|----------------|
| **Dijkstra** | 单源最短路（**不允许负权**） | 每轮选 dist 最小未确定点，用它松弛出边 | O(n²) |
| **Floyd** | 全源最短路 | 三重循环，允许以 k 为中转 | O(n³) |
| **Prim** | 最小生成树 | 从点集扩张：选连接 U 与 V−U 的最短边 | O(n²) |
| **Kruskal** | 最小生成树 | 边排序后贪心地选，并查集判环 | O(e log e) |

**Dijkstra 手工模拟表**（真题标准动作）：

```
轮次 | 选定顶点 | dist[A] dist[B] dist[C] ...  （已确定者加圈）
 1   |   A     |  0      5      ∞
 2   |   B     |         (5)    8
 ...
```

### 2.4 拓扑排序与关键路径

- 拓扑排序：反复取**入度 0** 顶点输出；可判有向图是否有环（输出 < n 个则有环）。
- **关键路径（AOE 网）**：
  1. 正向递推事件最早 ve(j) = max{ve(i) + w}；
  2. 反向递推事件最迟 vl(i) = min{vl(j) − w}；
  3. 活动余量 d = e(活动最迟) − e(活动最早)，**d = 0 的活动组成关键路径**；
  4. 关键路径可能不唯一；缩短关键活动时间才可能缩短工期。

---

## 四、易错点

- ⚠️ Dijkstra 不能处理负权边；每轮"选定即确定"，dist 不再回改。
- ⚠️ Prim 从**顶点**视角、Kruskal 从**边**视角——稀疏图用 Kruskal 更优。
- ⚠️ 拓扑序列不唯一；问"有几个拓扑序列"时要数排列。
- ⚠️ 关键路径上"所有"关键活动都缩短才可能缩短总工期（存在多条关键路径时）。
- ⚠️ 写代码时别忘了 `visited[]` 初始化和连通分量的外层 for 循环。
