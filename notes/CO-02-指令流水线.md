# CO-02 指令流水线

> 凸包顶点 · 组成原理 | 考频：3 次综合题（2012 / 2015 / 2018）| 难度：★★★★
> 定位：组原计算的"左边界"，与数据通路互为犄角——一个管时间重叠，一个管空间连接。

---

## 一、为什么它是凸包顶点

流水线在凸包左缘：考频 3 次但几乎每次都以"计算 + 分析"出现，且是理解
现代 CPU 的必经环节。它与数据通路（空间维度）共同框住组原 CPU 部分的上边界。

---

## 二、核心知识清单

### 2.1 五段流水（408 标准模型）

```
IF 取指 → ID 译码/取操作数 → EX 执行/算地址 → MEM 访存 → WB 写回
```

### 2.2 性能指标（计算题三板斧）

| 指标 | 公式 |
|------|------|
| 执行时间（k 段，每段 Δt） | **T = (k + n − 1)·Δt** |
| 吞吐率 TP | n / T = n / [(k+n−1)·Δt] |
| 加速比 S | T₀(串行) / T(流水) = n·k / (k+n−1) |
| 效率 E | 时空图占用面积 / 总面积 = n / (k+n−1) |

n → ∞ 时：S → k，TP → 1/Δt。
**段不均时**：瓶颈段决定节奏，T = Σ各段时间 + (n−1)·max(各段时间)。

### 2.3 三种冒险（重点）

| 冒险 | 成因 | 解决 |
|------|------|------|
| **结构冒险** | 硬件资源争用（如单口存储器取指与访存冲突） | 指令/数据 Cache 分离、多端口 |
| **数据冒险** | 后序指令需要前序未写回的结果（RAW） | **转发/旁路 forwarding**、阻塞 stall |
| **控制冒险** | 转移指令改变 PC，已预取的指令作废 | 分支预测、延迟槽、冲刷流水线 |

**关键细节**：
- RAW（写后读）是真相关；WAR/WAW 在简单五段流水中不出现。
- 有 forwarding 时，Load 指令紧接使用其结果仍需 **停 1 拍**（load-use 冒险）。
- 无条件转移在 EX 段确定方向时，误取 2 条 → 罚 2 拍（看模型约定）。

### 2.4 CPI 与总时钟数

```
实际 CPI = 理想 1 + 各类停顿/指令
总时钟数 = n(指令数) + k − 1(充满) + 总停顿拍数
```

---

## 三、典型考法

1. **流水时空图**：画指令流水线图，数完成 n 条指令的总拍数。
2. **冒险分析**：给一段指令序列，指出哪两条指令间有何种冒险、停几拍。
3. **性能计算**：给段延迟求 T / TP / 加速比，或比较有无 forwarding 的差别。
4. **超标量/超长指令字**：选择题考概念（空间并行 vs 时间并行）。

---

## 四、易错点

- ⚠️ T = (k+n−1)Δt 是"段等长且每段一拍"的理想模型；段不等长时换公式。
- ⚠️ "第几条指令在第几拍写回"要数格子，别只背公式。
- ⚠️ Load-use 即使有旁路也要停一拍——最常考的扣分点。
- ⚠️ 分支惩罚拍数取决于"哪一段确定转移结果"，题目模型不同答案不同。
- ⚠️ 吞吐率单位：条指令/单位时间，别漏乘 Δt。

## 例题精练（附答案）

### 例题 1：流水线性能计算

**题目**：5 段流水线，每段 1 ns。执行 100 条指令（无冒险），求总时间、吞吐率和加速比。

**参考答案**：
- T = (k + n − 1)·Δt = (5 + 100 − 1) × 1 ns = **104 ns**；
- 吞吐率 = n / T = 100 / 104 ≈ **0.96 条/ns**；
- 串行需 100 × 5 = 500 ns，加速比 S = 500 / 104 ≈ **4.8**（理论上限 k = 5）。

---

### 例题 2：数据冒险与停顿拍数

**题目**：五段流水线，有 forwarding。指令序列：

```
I1: LOAD  R1, 0(R2)      // R1 ← M[(R2)]
I2: ADD   R3, R1, R4     // 用 R1
I3: SUB   R5, R1, R6     // 又用 R1
```

问 I2、I3 各需停顿几拍？

**参考答案**：
- I1 的 LOAD 要到 **MEM 段结束**才有数据；I2 的 EX 段紧随 I1 的 MEM 段，MEM 结束时数据才能旁路 → **I2 停 1 拍**（经典 load-use 冒险，有旁路也躲不掉）。
- I3 的 EX 段时 I1 早已完成 MEM → 数据经旁路可得，**停 0 拍**。

若无 forwarding：I2 需等 I1 写回（WB）后再读 → 停 2 拍，I3 停 1 拍。

---

### 例题 3：流水时空图数拍

**题目**：4 条指令走 5 段流水，I3 是条件转移指令且在 EX 段判定转移成功（转移目标地址在 EX 末确定）。问完成 4 条指令共需多少拍？被冲刷几条？

**参考答案**：
- 无转移时 T = 5 + 4 − 1 = 8 拍；
- I3 在 EX 段（第 5 拍）才确定转移，此时 I4、I5（已预取的顺序下两条）作废 → **冲刷 2 条**；
- 实际执行 = I1、I2、I3 + 转移目标处重新取指 2 条算作 1 条有效（设目标指令为 I4'），即共 4 条有效指令（I1 I2 I3 I4'）；
- 总拍数 = 8 + **2 拍惩罚** = **10 拍**（冲刷的 2 条白占了 2 拍流水线槽位）。
