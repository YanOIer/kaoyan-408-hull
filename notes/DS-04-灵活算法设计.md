# DS-04 灵活算法设计（新趋势题）

> 凸包顶点 · 数据结构 | 考频：3 次综合题（2024 / 2025 / 2026，逐年加重）| 难度：★★★★★
> 定位：凸包最左侧的"难度天花板"——考频尚低但代表最新命题方向，决定高分段归属。

---

## 一、为什么它是凸包顶点

2024—2026 连续三年，数据结构算法设计题从"模板默写"转向"现场设计"：
- 2024：非常规结构上的算法设计；
- 2025：**最大最小值乘积**（划分数组使"最小值 × 长度（或和）"最大化）；
- 2026：BST 优化查找。

它位于凸包左上顶点——用最低的考频撑起最高的难度，是区分 110+ 与 130+ 的分水岭。

## 二、通用解题框架（四步法）

```
第1步：模型识别 —— 题目本质是什么？（划分/匹配/路径/计数/最优化）
第2步：暴力基准 —— 先写 O(n²) 或 O(n³) 保证有分
第3步：结构优化 —— 用什么数据结构/技巧降复杂度？
        排序预处理 | 双指针 | 单调栈 | 前缀和 | 分治 | 贪心
第4步：规范作答 —— 算法思想(文字) → 代码 → 复杂度分析
```

**评分规则意识**：408 算法设计题"思想分 + 代码分 + 复杂度分"三段给分，
即使写不出最优解，写出正确的次优解并如实标注复杂度，也能拿到大部分分数。

## 三、必备武器库

### 3.1 双指针

```c
// 有序数组中找和为 S 的数对：O(n)
int i = 0, j = n - 1;
while (i < j) {
    if (a[i] + a[j] == S) { /* 找到 */ }
    else if (a[i] + a[j] < S) i++;
    else j--;
}
```

### 3.2 单调栈（下一个更大元素类）

```c
// 求每个元素右侧第一个更大值：O(n)
for (int i = n - 1; i >= 0; i--) {
    while (!empty(S) && a[top(S)] <= a[i]) pop(S);
    nge[i] = empty(S) ? -1 : a[top(S)];
    push(S, i);
}
```

### 3.3 前缀和 / 前缀积

区间和 O(1) 查询：`sum[i..j] = P[j] − P[i−1]`。
"最大最小值乘积"类题的第一步往往是**排序 + 前缀和**把区间统计变成 O(1)。

### 3.4 分治与贪心直觉

- 分治：问题可拆且子问题独立（归并、快排、逆序对计数）。
- 贪心：每步局部最优能堆出全局最优（排序后贪心是 408 最常见的贪心形态）。

## 四、"最大最小值乘积"题型解剖（2025 真题方向）

题意范式：把数组（或序列）划分/选取成若干段，使 `min(段内元素) × f(段)` 最大。

破题要点：
1. **min 由谁决定？** —— 排序后，最值位置确定，把"最小值"枚举为锚点；
2. **枚举锚点 + 扩展区间**：以 a[i] 为最小值的最大合法区间（单调栈求左右边界）；
3. 乘积最大 ⟺ 在 a[i] 为最小值的范围内让 f(段) 最大；
4. 总复杂度：排序 O(n log n) + 单调栈 O(n)。

这套"**锚定最值 + 单调栈扩界**"的套路同样适用于：柱状图最大矩形、最大子矩阵等经典变体。

## 五、答题规范（阅卷友好）

```
【算法思想】用 3~5 句话说清：预处理什么、扫描什么、维护什么不变量。
【代码】变量命名贴近题意；关键行写注释；边界条件显式处理。
【复杂度】时间 O(?)、空间 O(?)，并说明理由。
```

## 六、易错点

- ⚠️ 只写代码不写思想 → 丢掉思想分；只写最优解没把握时，先交次优解。
- ⚠️ 边界：空数组、单元素、全相等——阅卷常设边界陷阱。
- ⚠️ 复杂度标注错误会被倒扣分，拿不准就写自己代码的真实复杂度。
