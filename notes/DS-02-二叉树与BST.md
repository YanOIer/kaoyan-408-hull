# DS-02 二叉树与 BST

> 定位：数据结构的"中流砥柱"，遍历与性质是算法设计题的基础设施。

二叉树位于凸包**右侧高频区**。五年一循环的综合题节奏极其稳定，2026 年最新真题

## 二、核心知识清单

### 2.1 二叉树的性质（选择题每年必考其一）

| 性质 | 公式 |
|------|------|
| 第 i 层结点数 | ≤ 2^(i-1) |
| 深度 k 总结点数 | ≤ 2^k − 1 |
| 叶结点数 | **n₀ = n₂ + 1**（最常用！） |
| 完全二叉树 | n 个结点深度 = ⌊log₂n⌋ + 1；编号 i 的父结点 ⌊i/2⌋，孩子 2i、2i+1 |

### 2.2 遍历（一切的基础）

```c
// 三种递归遍历：根的位置决定先/中/后序
void InOrder(BiTree T) {
    if (T) { InOrder(T->lchild); visit(T); InOrder(T->rchild); }
}
```

**非递归中序遍历**（综合题基本功）：

```c
void InOrderIter(BiTree T) {
    InitStack(S); BiTree p = T;
    while (p || !IsEmpty(S)) {
        if (p) { Push(S, p); p = p->lchild; }   // 一路向左
        else { Pop(S, p); visit(p); p = p->rchild; }  // 回退并访问，转右
    }
}
```

- 已知"先序+中序"或"后序+中序"可唯一确定二叉树；**先序+后序不能**。

### 2.3 二叉排序树 BST

- 性质：**中序遍历单调递增**。
- 查找：ASL 与树形相关，最好 O(log n)，最坏 O(n)（退化成单支树）。
- 插入：新结点一定是**叶子**；删除：双子结点用**中序直接前驱（或后继）**顶替。
- **2026 真题方向**：给定查找序列/约束，优化 BST 查找路径或判断合法查找序列。
  合法查找序列判定：序列中后续元素必须落在由已访问结点确定的合法区间内。

### 2.4 平衡二叉树 AVL 与哈夫曼树

- AVL：四种失衡调整 LL / RR / LR / RL；插入从失衡点向上调整一次即可。
- 哈夫曼：WPL = Σ 权值 × 路径长；**前缀编码**；n 个叶子的哈夫曼树共 2n−1 个结点。

## 三、典型考法

1. **性质计算**：给 n 求高度/结点数，或给结点分布求叶子数（n₀ = n₂ + 1 是钥匙）。
2. **遍历还原树** → 再求另一种遍历序列。
3. **BST 综合题**：构造、查找 ASL、删除后形态、合法查找序列。
4. **算法设计**：求树高、判断完全二叉树、找最近公共祖先——递归分治是通法。

---

## 四、易错点

- ⚠️ "二叉树第 i 层至多 2^(i−1)"中的 i 从 1 开始；空树高度定义看题目（0 或 −1）。
- ⚠️ BST 删除双子结点时，顶替后**原前驱结点的子树要正确接管**。
- ⚠️ 哈夫曼树不唯一，但 WPL 唯一。
- ⚠️ 完全二叉树数组编号从 1 开始才有 2i / 2i+1 关系。
