# CO-01 指令系统设计

> 定位：组原的"左上边界"——低频高难，但 2026 年重现，必须与数据通路打通。

## 一、为什么它是凸包顶点

指令系统考频最低（2 次），却是组原凸包的**左上顶点**：它向上连接数据通路
（数据通路综合题的指令格式就来自这里），向下定义了 CPU 能做什么。

## 二、核心知识清单

### 2.1 指令格式

```
| 操作码 OP | 地址码/操作数 A |
```

- **定长操作码**：n 位操作码 → 最多 2ⁿ 条指令。
- **扩展操作码（重点）**：地址数少的指令"借位"扩展操作码。
  例：16 位指令，三地址指令 OP 占 4 位；当三地址指令用完 N 种编码后，
  剩余编码空间可扩展为二地址指令（OP 扩到 8 位），依此类推。
  计算原则：**每种格式预留编码空间 = 上一级剩余编码 × 每多 4 位扩 16 倍**。

### 2.2 寻址方式（选择题 + 综合题必考）

| 寻址方式 | 有效地址 EA | 特点 |
|---------|------------|------|
| 立即寻址 | 操作数 = A | 快，范围受限 |
| 直接寻址 | EA = A | 一次访存 |
| 间接寻址 | EA = (A) | 多次访存，扩大寻址范围 |
| 寄存器寻址 | 操作数 = (R) | 不访存，最快 |
| 寄存器间接 | EA = (R) | 一次访存 |
| 相对寻址 | **EA = (PC) + A** | 浮动代码、转移指令 |
| 基址寻址 | EA = (基址R) + A | 程序重定位，OS 用 |
| 变址寻址 | EA = (变址R) + A | 数组遍历，A 为基准 |
| 堆栈寻址 | EA = (SP) | 隐式地址 |

**相对 vs 基址 vs 变址辨析**（真题高频陷阱）：
- 相对寻址：基准是 **PC**，为**程序浮动/转移**服务；
- 基址寻址：基准由 **OS 赋初值**，用户不变，为**重定位**服务；
- 变址寻址：基准 A 不变，**变址寄存器用户可改**，为**数组/循环**服务。

### 2.3 CISC 与 RISC

| | CISC | RISC |
|---|------|------|
| 指令数 | 多 | 少 |
| 指令长度 | 可变 | 定长 |
| 寻址方式 | 多 | 少 |
| 访存指令 | 任意 | **仅 Load/Store** |
| 控制 | 微程序 | 硬布线为主 |
| 流水线 | 难 | 易 |

## 三、典型考法

1. **扩展操作码计算**：给指令字长和各格式条数，问能否实现 / 最多几条。
2. **寻址方式计算**：给机器码求有效地址、取到的操作数（结合内存内容表）。
3. **与数据通路结合（2026 方向）**：设计一条指令的格式 + 写出它的微操作流程。

---

## 四、易错点

- ⚠️ 扩展操作码：低地址数格式消耗的是高地址数格式"剩下的编码"，不是全部 2ⁿ。
- ⚠️ 相对寻址取指后 **PC 已 +1**，EA = (PC)+A 用的是加过 1 的值（看题目约定）。
- ⚠️ 间接寻址的地址码可能还要经过"间址位"多次解析。
- ⚠️ RISC 不等于"指令少"而已，**定长 + Load/Store 结构 + 硬布线**才是本质。
