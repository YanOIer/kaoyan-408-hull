## 二、核心知识清单

### 2.1 指令格式

```
| 操作码 OP | 地址码/操作数 A |
```

- **定长操作码**：n 位操作码 → 最多 2ⁿ 条指令。
- **扩展操作码（重点）**：地址数少的指令"借位"扩展操作码。
  例：16 位指令，三地址指令 OP 占 4 位；当三地址指令用完 N 种编码后，
  剩余编码空间可扩展为二地址指令（OP 扩到 8 位），依此类推。
  计算原则：**每种格式预留编码空间 = 上一级剩余编码 × 每多 4 位扩 16 倍**。

### 2.2 寻址方式（选择题 + 综合题必考）

| 寻址方式 | 有效地址 EA | 特点 |
|---------|------------|------|
| 立即寻址 | 操作数 = A | 快，范围受限 |
| 直接寻址 | EA = A | 一次访存 |
| 间接寻址 | EA = (A) | 多次访存，扩大寻址范围 |
| 寄存器寻址 | 操作数 = (R) | 不访存，最快 |
| 寄存器间接 | EA = (R) | 一次访存 |
| 相对寻址 | **EA = (PC) + A** | 浮动代码、转移指令 |
| 基址寻址 | EA = (基址R) + A | 程序重定位，OS 用 |
| 变址寻址 | EA = (变址R) + A | 数组遍历，A 为基准 |
| 堆栈寻址 | EA = (SP) | 隐式地址 |

**相对 vs 基址 vs 变址辨析**（真题高频陷阱）：
- 相对寻址：基准是 **PC**，为**程序浮动/转移**服务；
- 基址寻址：基准由 **OS 赋初值**，用户不变，为**重定位**服务；
- 变址寻址：基准 A 不变，**变址寄存器用户可改**，为**数组/循环**服务。

### 2.3 CISC 与 RISC

| | CISC | RISC |
|---|------|------|
| 指令数 | 多 | 少 |
| 指令长度 | 可变 | 定长 |
| 寻址方式 | 多 | 少 |
| 访存指令 | 任意 | **仅 Load/Store** |
| 控制 | 微程序 | 硬布线为主 |
| 流水线 | 难 | 易 |

## 三、典型考法

1. **扩展操作码计算**：给指令字长和各格式条数，问能否实现 / 最多几条。
2. **寻址方式计算**：给机器码求有效地址、取到的操作数（结合内存内容表）。
3. **与数据通路结合（2026 方向）**：设计一条指令的格式 + 写出它的微操作流程。

---

## 四、易错点

- ⚠️ 扩展操作码：低地址数格式消耗的是高地址数格式"剩下的编码"，不是全部 2ⁿ。
- ⚠️ 相对寻址取指后 **PC 已 +1**，EA = (PC)+A 用的是加过 1 的值（看题目约定）。
- ⚠️ 间接寻址的地址码可能还要经过"间址位"多次解析。
- ⚠️ RISC 不等于"指令少"而已，**定长 + Load/Store 结构 + 硬布线**才是本质。

## 例题精练（附答案）

### 例题 1：扩展操作码（经典必会题）

**题目**：指令字长 16 位，每个地址码 4 位。已设计三地址指令 15 条、二地址指令 15 条、一地址指令 15 条，问零地址指令最多还能设计多少条？

**参考答案**：**16 条**。

账簿推算：
1. 三地址：OP 4 位共 16 种编码，用 15 条（0000—1110），**留 1111** 作扩展窗口；
2. 二地址：1111 扩展出 16 种（1111 0000—1111 1111），用 15 条，**留 1111 1111**；
3. 一地址：再扩 16 种，用 15 条，**留 1111 1111 1111**；
4. 零地址：1111 1111 1111 0000 — 1111 1111 1111 1111，共 **16** 种全可用。

**口诀**：每留一个窗口，下一级多 2⁴ = 16 个编码。

### 例题 2：寻址方式求有效地址

**题目**：指令中地址码 A = 200H，PC = 3000H（取指后已 +2），基址寄存器 = 1000H，变址寄存器 = 0100H，内存单元 (200H) = 4000H。分别求直接寻址、间接寻址、相对寻址、基址寻址、变址寻址的有效地址。

**参考答案**：

| 寻址方式 | 计算 | EA |
|---------|------|-----|
| 直接 | A | **200H** |
| 间接 | (A) | **4000H** |
| 相对 | (PC) + A = 3002H + 200H | **3202H** |
| 基址 | (基址R) + A = 1000H + 200H | **1200H** |
| 变址 | (变址R) + A = 0100H + 200H | **0300H** |

⚠️ 相对寻址用**取指后**的 PC 值（3000H+2），这是阅卷经典陷阱。

### 例题 3：RISC 特征辨析

**题目**：下列关于 RISC 的叙述中，错误的是：
A. 指令长度固定 　B. 只有 Load/Store 指令访存 　C. 主要采用微程序控制器 　D. 寄存器数量多

**参考答案**：选 **C**。RISC 以**硬布线控制器**为主（指令规整、执行快）；微程序控制器是 CISC 的典型实现方式。A、B、D 均为 RISC 正确特征。
