DS-03 图算法（DFS / BFS / Dijkstra / 最小生成树）

凸包顶点 · 数据结构 | 考频：5 次综合题（2012 / 2015 / 2018 / 2022 / 2023）| 难度：★★★★★ 定位：数据结构综合题的"天花板"，408 全卷难度的右上边界之一。

一、为什么它是凸包顶点

图算法占据凸包右上角：高频 + 最高难度。2022 年直接要求手写 Dijkstra 代码， 标志图算法从"手工模拟"升级为"完整代码实现"。拿下它，数据结构才有冲高分的资本。

二、核心知识清单

2.1 存储结构（选择结构 = 选对复杂度）

结构 空间 适用 判边 (i,j) 遍历出边
邻接矩阵 O(n²) 稠密图 O(1) O(n)
邻接表 O(n+e) 稀疏图 O(度) O(度)

十字链表（有向图）、邻接多重表（无向图）——选择题考定义。

2.2 遍历（必背代码）

// DFS —— 递归即栈
void DFS(Graph G, int v) {
    visited[v] = true; visit(v);
    for (w = FirstAdj(G, v); w >= 0; w = NextAdj(G, v, w))
        if (!visited[w]) DFS(G, w);
}

// BFS —— 队列
void BFS(Graph G, int v) {
    InitQueue(Q); visited[v] = true; EnQueue(Q, v);
    while (!IsEmpty(Q)) {
        DeQueue(Q, v); visit(v);
        for (w = FirstAdj(G, v); w >= 0; w = NextAdj(G, v, w))
            if (!visited[w]) { visited[w] = true; EnQueue(Q, w); }
    }
}

复杂度：邻接表 O(n+e)，邻接矩阵 O(n²)。

2.3 四大应用算法（手工模拟必考）

算法 问题 核心操作 复杂度(邻接矩阵)
Dijkstra 单源最短路（不允许负权） 每轮选 dist 最小未确定点，用它松弛出边 O(n²)
Floyd 全源最短路 三重循环，允许以 k 为中转 O(n³)
Prim 最小生成树 从点集扩张：选连接 U 与 V−U 的最短边 O(n²)
Kruskal 最小生成树 边排序后贪心地选，并查集判环 O(e log e)

Dijkstra 手工模拟表（真题标准动作）：

轮次 | 选定顶点 | dist[A] dist[B] dist[C] ...  （已确定者加圈）
 1   |   A     |  0      5      ∞
 2   |   B     |         (5)    8
 ...

2.4 拓扑排序与关键路径

  • 拓扑排序：反复取入度 0 顶点输出；可判有向图是否有环（输出 < n 个则有环）。
  • 关键路径（AOE 网）：
  • 正向递推事件最早 ve(j) = max{ve(i) + w}；
  • 反向递推事件最迟 vl(i) = min{vl(j) − w}；
  • 活动余量 d = e(活动最迟) − e(活动最早)，d = 0 的活动组成关键路径；
  • 关键路径可能不唯一；缩短关键活动时间才可能缩短工期。

三、典型考法

  1. 手工模拟：Dijkstra 逐轮 dist 表、Prim/Kruskal 选边序列、拓扑序列个数。
  2. 代码题：DFS/BFS 框架改造（判连通、求路径、判环）；2022 Dijkstra 完整代码。
  3. 关键路径综合：画 AOE → 求 ve/vl → 找关键路径 → 分析工期变化。

四、易错点

  • ⚠️ Dijkstra 不能处理负权边；每轮"选定即确定"，dist 不再回改。
  • ⚠️ Prim 从顶点视角、Kruskal 从边视角——稀疏图用 Kruskal 更优。
  • ⚠️ 拓扑序列不唯一；问"有几个拓扑序列"时要数排列。
  • ⚠️ 关键路径上"所有"关键活动都缩短才可能缩短总工期（存在多条关键路径时）。
  • ⚠️ 写代码时别忘了 visited[] 初始化和连通分量的外层 for 循环。

五、复习建议

  1. 每天默写 DFS/BFS，直到 3 分钟无错默出；
  2. 手工模拟各做 5 题：Dijkstra 表、Prim、Kruskal、拓扑、关键路径；
  3. 精做 2012/2015/2018/2022/2023 图综合题，2022 年的代码题要能达到"默写级"熟练。

例题精练（附答案）

例题 1：Dijkstra 手工模拟

题目：无向带权图顶点 A—E，边：AB=6, AC=3, BC=2, BD=5, CD=3, CE=4, DE=2, BE=10。求 A 到各顶点的最短路径。

参考答案：

轮次 选定 dist B dist C dist D dist E
初始 A 6 3 ∞ ∞
1 C(3) 5(3+2) — 6 7
2 B(5) — — 6 7
3 D(6) — — — 7
4 E(7) — — — —
  • A→C = 3，A→C→B = 5，A→C→D = 6，A→C→E = 7。
  • 注意第 1 轮：经 C 松弛 B 由 6 → 5（dist 会被更新，直到该点被"选定"才锁定）。

例题 2：拓扑排序与判环

题目：有向图边集 {A→B, A→C, B→D, C→D, D→E}。给出一个拓扑序列，并说明若添加边 E→B 会怎样。

参考答案： - 一个合法拓扑序列：A, C, B, D, E（A B C D E 也对——拓扑序不唯一）。 - 添加 E→B 后形成 B→D→E→B 有向环 → 不存在拓扑序列。用"入度 0"算法验证：A 输出后，B/C/D/E 均无法全部入度归零（B 被 E 指着、E 被 D 指着、D 被 B、C 指着……），输出个数 < 5 ⟹ 判环成立。

例题 3：关键路径

题目：AOE 网：v1→v2(3)，v1→v3(2)，v2→v4(2)，v3→v4(4)，v4→v5(3)，v3→v5(1)。求关键路径和工期。

参考答案： - ve：ve(1)=0；ve(2)=3；ve(3)=2；ve(4)=max(3+2, 2+4)=6；ve(5)=max(6+3, 2+1)=9。 - vl：vl(5)=9；vl(4)=9−3=6；vl(3)=min(6−4, 9−1)=2；vl(2)=6−2=4；vl(1)=min(4−3, 2−2)=0。 - 活动余量：v3→v4：e=ve(3)=2，l=vl(4)−4=2，余量 0 ✅；v4→v5：e=6，l=6，余量 0 ✅；v1→v3：e=0，l=0，余量 0 ✅。 - 关键路径：v1→v3→v4→v5，工期 = 9。
