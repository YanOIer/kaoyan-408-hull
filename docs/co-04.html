CO-04 CPU 数据通路设计

凸包顶点 · 组成原理 | 考频：7 次综合题（2016 / 2019 / 2022 / 2023 / 2024 / 2025 / 2026）| 难度：★★★★★ 定位：408 全卷最硬的顶点——考频最高、难度最高的"双料冠军"，组原综合题的固定席位。

一、为什么它是凸包顶点

数据通路以 7 次考频 + 5 星难度 雄踞凸包最右上角，是整个 408 知识空间中 "离原点最远"的点。2016 年固定为综合大题后从未缺席，2024—2026 连续三年出现。 拿下数据通路 ≈ 拿下组原的半壁江山。

二、核心知识清单

2.1 数据通路的基本部件

部件 作用
PC 存放下条指令地址
IR 存放当前指令
MAR / MDR 访存地址/数据寄存器
ALU + 暂存器 运算；单总线结构需暂存器暂存一个操作数
通用寄存器组 操作数与结果
三态门 / 多路选择器 控制数据流向
控制单元 CU 发出微操作控制信号

2.2 指令执行的微操作序列（核心能力）

标准流程：取指（所有指令相同）→ 间址（可选）→ 执行 → 中断检查。

取指周期（必背，任何题的第一段）：

节拍1: (PC) → MAR          控制信号: PCout, MARin
节拍2: 1 → R/W(读); M(MAR) → MDR;  (PC)+1 → PC
节拍3: (MDR) → IR          控制信号: MDRout, IRin
       CU 对 IR 中操作码译码

执行周期示例（加法 ADD R0, (R1)，单总线模型）：

(R1) → MAR → 读主存 → MDR → Y(暂存)
(R0) + (Y) → Z → R0

写微操作的三条军规： 1. 每个节拍内，总线上只能有一个来源（单总线模型）； 2. 控制信号成对出现：Xout 与 Yin 同时有效才能完成 X→Y； 3. 需要 ALU 运算时，一个操作数必须先进暂存器 Y。

2.3 单周期 / 多周期 / 流水对比

单周期 多周期 流水线
CPI 1 >1（指令间不同） 理想 1
时钟周期 最长指令决定（很长） 最长微操作决定（短） 最长段决定
硬件 部件不能复用 部件可复用 段间加寄存器

2.4 硬布线 vs 微程序控制器

硬布线 微程序
速度 快 慢
设计/修改 难 易（改微码）
适用 RISC CISC
核心概念 状态机 微指令 = 控制信号集合；微程序存于控制存储器 CM

微指令格式：操作控制字段 + 顺序控制字段（下址字段/断定方式）。

三、典型考法

  1. 补全微操作序列：给数据通路图 + 指令，写出取指+执行的逐拍微操作和控制信号。
  2. 数据通路设计：给指令集需求，设计通路结构（选部件、连总线）。
  3. 节拍计算：单总线/双总线/三总线下某指令需要几拍，CPI 多少。
  4. 微程序设计：确定微指令格式、微地址形成方式、控存容量。

四、易错点

  • ⚠️ 取指阶段 (PC)+1→PC 的"1"是指令字长对应的地址增量，按字节编址且指令 32 位时可能是 +4。
  • ⚠️ 单总线模型 ALU 的两个操作数不能同拍上传——必须一个先存 Y。
  • ⚠️ MDR 与主存的数据交换方向：读是 M(MAR)→MDR，写是 MDR→M(MAR)，控制信号不同。
  • ⚠️ 写控制信号时 out/in 配对漏一个是阅卷扣分重灾区。
  • ⚠️ 微程序存在控制存储器里，不在主存——选择题经典陷阱。

五、复习建议

  1. 默写取指周期到形成肌肉记忆——所有题的公共开头；
  2. 精做 2016 / 2019 / 2022—2026 共 7 道数据通路真题，逐题总结"指令 → 微操作"的翻译套路；
  3. 自制一张空白单总线数据通路图，随机抽指令（LOAD / STORE / ADD / JMP / 间址指令）练习写全程；
  4. 与流水线打通：同一条指令在五段流水里各做什么，与多周期的微操作对照理解。

例题精练（附答案）

例题 1：写出 LOAD 指令的完整微操作序列

题目：单总线数据通路（含 PC、IR、MAR、MDR、Y、Z、R0—R3），写出 LOAD R1, (R2)（R1 ← M[(R2)]）的取指 + 执行微操作及控制信号。

参考答案：

取指周期（所有指令相同）：

T1: (PC) → MAR            PCout, MARin
T2: M(MAR) → MDR          MEMR（读）; (PC)+1 → PC：PCout, +1
T3: (MDR) → IR            MDRout, IRin

执行周期：

T4: (R2) → MAR            R2out, MARin        // 形式地址 = (R2)
T5: M(MAR) → MDR          MEMR                // 读主存
T6: (MDR) → R1            MDRout, R1in        // 写入目标寄存器

共 6 拍。注意：LOAD 不用 ALU，无需经 Y/Z 暂存。

例题 2：单总线 ADD 指令的节拍

题目：同上通路，写出 ADD R0, R1（R0 ← (R0)+(R1)）的执行周期微操作，并说明为什么比双总线多一拍。

参考答案：

T1: (R0) → Y              R0out, Yin     // 一个操作数先进暂存器
T2: (R1) + (Y) → Z        R1out, ADD, Zin
T3: (Z) → R0              Zout, R0in

为什么多一拍：单总线同一时刻只能传一个数据，ALU 的两个操作数不能同时送达，必须先把 R0 锁进暂存器 Y。双总线结构可让 R0、R1 同拍到达 ALU 两端，执行周期可省一拍（2 拍完成）。

例题 3：微程序控制器概念题

题目：微程序存放在（　）中。 A. 主存 　B. 控制存储器 　C. 指令寄存器 　D. 通用寄存器

参考答案：选 B。

微程序由微指令组成，存放在 CPU 内部的控制存储器（CM）中，是只读的、出厂固化（或可微码更新）的。主存里放的是机器指令，不是微指令——这是最高频的混淆点。

补充：一条机器指令 ⟺ 一段微程序；微指令 = 操作控制字段（发出哪些控制信号）+ 顺序控制字段（下一条微指令地址怎么来）。
