DS-04 灵活算法设计（新趋势题）

凸包顶点 · 数据结构 | 考频：3 次综合题（2024 / 2025 / 2026，逐年加重）| 难度：★★★★★ 定位：凸包最左侧的"难度天花板"——考频尚低但代表最新命题方向，决定高分段归属。

一、为什么它是凸包顶点

2024—2026 连续三年，数据结构算法设计题从"模板默写"转向"现场设计"： - 2024：非常规结构上的算法设计； - 2025：最大最小值乘积（划分数组使"最小值 × 长度（或和）"最大化）； - 2026：BST 优化查找。

它位于凸包左上顶点——用最低的考频撑起最高的难度，是区分 110+ 与 130+ 的分水岭。

二、通用解题框架（四步法）

第1步：模型识别 —— 题目本质是什么？（划分/匹配/路径/计数/最优化）
第2步：暴力基准 —— 先写 O(n²) 或 O(n³) 保证有分
第3步：结构优化 —— 用什么数据结构/技巧降复杂度？
        排序预处理 | 双指针 | 单调栈 | 前缀和 | 分治 | 贪心
第4步：规范作答 —— 算法思想(文字) → 代码 → 复杂度分析

评分规则意识：408 算法设计题"思想分 + 代码分 + 复杂度分"三段给分， 即使写不出最优解，写出正确的次优解并如实标注复杂度，也能拿到大部分分数。

三、必备武器库

3.1 双指针

// 有序数组中找和为 S 的数对：O(n)
int i = 0, j = n - 1;
while (i < j) {
    if (a[i] + a[j] == S) { /* 找到 */ }
    else if (a[i] + a[j] < S) i++;
    else j--;
}

3.2 单调栈（下一个更大元素类）

3.3 前缀和 / 前缀积

区间和 O(1) 查询：sum[i..j] = P[j] − P[i−1]。 "最大最小值乘积"类题的第一步往往是排序 + 前缀和把区间统计变成 O(1)。

3.4 分治与贪心直觉

  • 分治：问题可拆且子问题独立（归并、快排、逆序对计数）。
  • 贪心：每步局部最优能堆出全局最优（排序后贪心是 408 最常见的贪心形态）。

四、"最大最小值乘积"题型解剖（2025 真题方向）

题意范式：把数组（或序列）划分/选取成若干段，使 min(段内元素) × f(段) 最大。

破题要点： 1. min 由谁决定？ —— 排序后，最值位置确定，把"最小值"枚举为锚点； 2. 枚举锚点 + 扩展区间：以 a[i] 为最小值的最大合法区间（单调栈求左右边界）； 3. 乘积最大 ⟺ 在 a[i] 为最小值的范围内让 f(段) 最大； 4. 总复杂度：排序 O(n log n) + 单调栈 O(n)。

这套"锚定最值 + 单调栈扩界"的套路同样适用于：柱状图最大矩形、最大子矩阵等经典变体。

五、答题规范（阅卷友好）

【算法思想】用 3~5 句话说清：预处理什么、扫描什么、维护什么不变量。
【代码】变量命名贴近题意；关键行写注释；边界条件显式处理。
【复杂度】时间 O(?)、空间 O(?)，并说明理由。

六、易错点

  • ⚠️ 只写代码不写思想 → 丢掉思想分；只写最优解没把握时，先交次优解。
  • ⚠️ 边界：空数组、单元素、全相等——阅卷常设边界陷阱。
  • ⚠️ 复杂度标注错误会被倒扣分，拿不准就写自己代码的真实复杂度。

七、复习建议

  1. 每周 2 道"非模板"算法题（LeetCode 中等难度即可），刻意练习四步法；
  2. 把"单调栈 / 双指针 / 前缀和 / 分治"各整理 2 个模板题；
  3. 精研 2024 / 2025 / 2026 三年真题的官方评分标准，学会"分段拿分"。

例题精练（附答案）

例题 1：双指针（有序数组两数之和）

题目：有序数组 a = [1, 3, 5, 7, 9, 11]，S = 14。判断是否存在两数之和为 S，并给出下标。

参考答案： - i=0(1), j=5(11)：和 12 < 14 → i++ - i=1(3), j=5(11)：和 14 ✅ - 存在：a[1]=3 与 a[5]=11。时间 O(n)，空间 O(1)。

若用哈希法则 O(n) 时间 + O(n) 空间——有序这个条件就是用双指针的信号。

例题 2：单调栈（柱状图最大矩形）

题目：heights = [2, 1, 5, 6, 2, 3]，求柱状图中最大矩形面积。

参考答案：10。

思路（锚定最值 + 单调栈扩界）：以每根柱子为高，向左右扩展到第一根更矮的柱子。 - 高度 5（下标 2）：左界到 1，右界到 4 → 宽 3，面积 15？❌ 注意下标 3 的 6 ≥ 5，可继续扩，右界是下标 4（值 2 < 5），左界是下标 1（值 1 < 5）→ 实际宽 = 4−1−1 = 2，面积 = 5×2 = 10。 - 其余柱子均不超过 10。

答案 = 10（高 5、跨下标 2—3 的矩形）。单调栈一次遍历 O(n) 求出所有"左右第一更矮"边界。

例题 3：按四步法做"最大最小值乘积"类题

题目（仿 2025）：把数组 [4, 2, 7, 5] 划分成若干连续段，求 max（段内最小值 × 段长）的划分方案值。（枚举所有可能，单段也算）

参考答案： 1. 模型识别：最优划分中，每一段的"最小值"一定出现在段内；考虑以每个元素为最小值的最大扩展区间。 2. 暴力基准：枚举所有 O(n²) 段取最大，n=4 完全可以。 3. 枚举验证： - 整段 [4,2,7,5]：min=2，值 = 2×4 = 8； - 段 [4]：4×1=4；段 [7]：7；段 [5]：5； - 段 [7,5]：5×2=10 ✅ 当前最大； - 段 [2,7,5]：2×3=6；段 [4,2]：2×2=4；段 [2,7]：2×2=4。 4. 最优 = 10，划分为 [4] [2] [7,5]（段 [7,5] 贡献 10）。

考场上数据规模大时，用"排序 + 单调栈"把枚举优化到 O(n log n)，但写出 O(n²) 正确解并标注复杂度，也能拿大部分分。
