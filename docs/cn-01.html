CN-01 时延计算

凸包顶点 · 计算机网络 | 考频：5 次综合题（2010 / 2013 / 2016 / 2019 / 2022）| 难度：★★ 定位：网络凸包的"左下锚点"——五年一循环的计算题，套路固定，必须零失误。

一、为什么它是凸包顶点

时延计算考频 5 次、难度仅 2 星，是网络凸包的最左边界。它把"物理层/链路层"的 计算封进凸包：公式只有两三个，但单位换算和时序分析是粗心重灾区。

二、核心知识清单

2.1 四种时延

时延 公式 发生在
发送（传输）时延 帧长 / 发送速率 网卡把比特推上链路
传播时延 距离 / 电磁波速（2×10⁸ m/s） 信号在介质中跑
处理时延 检错、查表 路由器
排队时延 等输出链路空闲 路由器队列

黄金辨析：发送时延看数据量和带宽，传播时延看距离——两者毫无关系。

2.2 三种交换方式对比（常结合时延一起考）

电路交换 报文交换 分组交换
建立连接 需要（建立时延） 不需要 数据报不需要
存储转发 不 整报文 分组
时延构成 建立 + 传播 逐跳存储转发 逐跳存储转发 + 流水线效应

2.3 分组交换的"流水线"计算（大题核心）

报文 L bit，分成 p 个分组（每个分组数据 + 首部 h），经 k 段链路（k−1 个中间节点），速率 R：

总时延 ≈ 最后一个分组走完全程的时间
      = 源点发出全部 p 个分组的时间 + 最后一个分组再经 (k−1) 跳存储转发 + 各段传播时延
      = p×(分组长/R) + (k−1)×(分组长/R) + k×传播时延

口诀：源头发完所有分组，末尾分组还要再过 (k−1) 关。

2.4 配套小考点

  • 带宽时延积 = 传播时延 × 带宽 = "链路上能装多少比特"；
  • 信道利用率 = 发送时间 / 总周期时间；
  • 奈氏准则（无噪声）：C = 2W·log₂V；香农（有噪声）：C = W·log₂(1+S/N)。

三、典型考法

  1. 给报文大小、分组大小、链路数、速率、距离 → 求总时延；
  2. 比较电路/报文/分组交换在同一场景下的时延大小；
  3. 求"分组多长时时延最小"或"第几个分组到达时…"之类的时序问题。

解题流程：画时序草图 → 列每个分组的旅程 → 找"最后到达者" → 分类加总。

四、易错点

  • ⚠️ 单位：1 KB = 1024 B = 8192 bit；速率 Mbps 是 10⁶ bit/s，别混 1024 和 1000。
  • ⚠️ 电磁波速 2×10⁸ m/s（真空中 3×10⁸），题目默认铜线/光纤用 2×10⁸。
  • ⚠️ 首部开销：分组越小分组数越多，首部总量越大——两头都要算。
  • ⚠️ 忽略处理/排队时延是题目明示的默认假设，别自己加戏。
  • ⚠️ 多跳时每跳都有一次"存储转发"，但发送时延只在源点发全部分组时占大头。

五、复习建议

  1. 把 2010/2013/2016/2019/2022 五道时延题集中做一遍，总结共性；
  2. 自制 3 组不同参数互换条件（改链路数/分组大小）重算，检验公式鲁棒性；
  3. 与 TCP 吞吐量（CN-03）打通：时延带宽积是理解滑动窗口的钥匙。

例题精练（附答案）

例题 1：发送时延 vs 传播时延

题目：在 100 Mbps 链路上发送 1000 B 的帧，链路长 1 km（电磁波速 2×10⁸ m/s）。求发送时延和传播时延。

参考答案： - 发送时延 = 帧长 / 速率 = (1000 × 8) / 10⁸ = 80 μs； - 传播时延 = 距离 / 波速 = 1000 / (2×10⁸) = 5 μs； - 本例发送时延 ≫ 传播时延；若帧只有 64 B，则发送 5.12 μs，两者相当——谁占主导取决于数据量和距离，二者没有任何换算关系。

例题 2：分组交换的流水线时延（大题原型）

题目：报文 L = 10⁷ bit，分成 1000 bit 数据 + 100 bit 首部的分组，链路速率 10 Mbps，共 3 段链路（2 个中间节点），忽略传播/处理时延。比较报文交换与分组交换的总时延。

参考答案： - 报文交换：每跳存储转发 10⁷/10⁷ = 1 s，3 跳共 3 s； - 分组交换：分组数 p = 10⁷/1000 = 10000 个，每组长 1100 bit； - 源发完全部分组：10000 × 1100/10⁷ = 1.1 s； - 最后一个分组再过 2 个中间节点：2 × 1100/10⁷ = 0.22 ms； - 总计 ≈ 1.10022 s，约为报文交换的 1/3。

跳数越多，分组交换的优势越明显。

例题 3：奈氏 vs 香农

题目：带宽 3 kHz 的信道，(1) 无噪声、8 电平调制，最大速率？(2) 信噪比 30 dB（S/N = 1000），香农极限？

参考答案： - 奈氏：C = 2W·log₂V = 2 × 3000 × log₂8 = 6000 × 3 = 18 kbps； - 香农：C = W·log₂(1+S/N) = 3000 × log₂1001 ≈ 3000 × 9.97 ≈ 30 kbps； - 实际极限取两者较小值：min(18, 30) = 18 kbps。
