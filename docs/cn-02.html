CN-02 IP 子网划分与路由聚合

凸包顶点 · 计算机网络 | 考频：6 次综合题（2009 / 2012 / 2015 / 2018 / 2021 / 2024）| 难度：★★ 定位：网络考频并列第一的"右下顶点"——三年一循环，纯计算，网络 25 分的压舱石。

二、为什么它是凸包顶点

子网划分 6 次考频与 TCP 并列第一，难度全科目最低之一。它是凸包的右下角锚点： 用最基础的二进制运算，换网络大题的稳定满分。任何一年都可能在综合题出现。

二、核心知识清单

2.1 IP 地址与子网掩码

  • IPv4 地址 32 bit，点分十进制；
  • 网络号 = IP AND 掩码；
  • 特殊地址：全 0 主机号 = 网络地址；全 1 主机号 = 直接广播地址——都不可分配；
  • 可用主机数 = 2^(主机位数) − 2。

2.2 子网划分（VLSM）标准流程

需求：把 X.0.0.0/16 分给 n 个部门，各部门需要 mᵢ 台主机

1. 按主机需求从大到小排序
2. 每个部门：主机位 hᵢ = ⌈log₂(mᵢ + 2)⌉，前缀 = 32 − hᵢ
3. 从地址块起点顺序切分，保证边界对齐（块大小必须是 2 的幂）
4. 写出每个子网：网络地址 / 掩码 / 广播地址 / 可用范围

对齐原则：一个 2^k 大小的子网，其网络地址必须是 2^k 的倍数。

2.3 路由聚合（CIDR 超网）

  • 找各网络地址的最长公共前缀 → 聚合网络号；
  • 聚合条件：地址块连续、数量为 2 的幂、对齐；
  • 最长前缀匹配：路由表多条命中时，选掩码最长者；
  • 默认路由 0.0.0.0/0 最后匹配。

2.4 配套考点

概念 要点
NAT 私有地址 ↔ 公有地址转换；私有段 10/8、172.16/12、192.168/16
ARP IP → MAC，广播询问单播应答，只在同一局域网内
路由器 vs 交换机 路由器隔离广播域；交换机不隔离
分片 MTU 限制，片偏移以 8 字节为单位

三、典型考法

  1. 划分子网：给地址块 + 部门需求 → 输出分配方案（真题最常见的 9 分结构）；
  2. 聚合路由：给路由表若干条目 → 聚合 + 判断某目的 IP 走哪条；
  3. 辨析地址：给 IP/掩码 → 求网络号、广播号、可用主机数、是否同网段。

四、易错点

  • ⚠️ 可用主机数减 2：网络地址 + 广播地址不能分。
  • ⚠️ 子网边界必须 2 的幂对齐——"从前往后顺序排"前先按需求从大到小排序。
  • ⚠️ /31、/32 是特殊用途（点对点链路、主机路由），常规划分按 −2 处理。
  • ⚠️ 聚合时公共前缀位数要数二进制位，别看十进制像就合并。
  • ⚠️ 最长前缀匹配优先于一切——默认路由永远最后考虑。

五、复习建议

  1. 准备一张 2 的幂次表（2⁰—2¹⁶）贴在手边，练到秒答主机位数；
  2. 精做 2009/2012/2015/2018/2021/2024 六道真题，体会"同一道计算题的六次换装"；
  3. 目标：网络大题 8—10 分钟拿满分，为其他科目让出时间。

例题精练（附答案）

例题 1：VLSM 变长子网划分（大题原型）

题目：把 192.168.1.0/24 分给三个部门：A 需 100 台主机，B 需 50 台，C 需 25 台。给出不浪费的划分方案。

参考答案（需求从大到小切）：

部门 主机数 主机位 ⌈log₂(n+2)⌉ 前缀 网络地址 可用范围
A 100 7（2⁷−2=126 ✅） /25 192.168.1.0/25 .1 — .126
B 50 6（2⁶−2=62 ✅） /26 192.168.1.128/26 .129 — .190
C 25 5（2⁵−2=30 ✅） /27 192.168.1.192/27 .193 — .222

检查对齐：128 是 64 的倍数 ✅，192 是 32 的倍数 ✅。剩余 .224/27 可备用。

例题 2：路由聚合与最长前缀匹配

题目：(1) 聚合 172.16.0.0/24、172.16.1.0/24、172.16.2.0/24、172.16.3.0/24；(2) 路由表中有 172.16.0.0/22 和 172.16.2.0/24 两条，目的地址 172.16.2.5 走哪条？

参考答案： - (1) 4 个 /24 的第 3 字节 0—3 = 00000000—00000011，公共前缀 22 位 → 172.16.0.0/22； - (2) 两条都命中，选掩码更长的 172.16.2.0/24（最长前缀匹配原则）。

例题 3：地址辨析快算

题目：主机 IP 192.168.5.121/27。求网络地址、广播地址、可用主机数，并判断 192.168.5.100/27 是否与它同网段。

参考答案： - /27 → 掩码 255.255.255.224，主机位 5 位，块大小 32； - 121 = 96 + 25 → 落在 96—127 块：网络地址 192.168.5.96/27，广播 192.168.5.127，可用 2⁵−2 = 30 台； - 100 落在 96—127 块（96 + 4）→ 网络地址同为 192.168.5.96 → 同网段 ✅。
