使用建议

  1. 先看凸包图：知道四科边界在哪里，再决定时间分配。
  2. 从右下顶点开始（性价比高）：CN-02 子网划分 → CN-01 时延计算 → OS-02 文件系统 → DS-01 栈与队列。
  3. 攻右上顶点（决定上限）：CO-04 数据通路 → DS-03 图算法 → OS-03 PV 操作 → CN-03 TCP。
  4. 补左上顶点（冲 130+）：DS-04 灵活算法设计 → CO-01 指令系统 → CO-02 流水线。
  5. 每篇笔记的「真题锚点」对应侧栏「真题数据」中的年份整理，精做对应年份综合题。
  6. 凸包内部的点（如排序代码、内存管理）同样必考——顶点划定边界，内部点靠顶点间的连线知识覆盖。
